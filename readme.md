
# SolanaQuest

**SolanaQuest** is a learn-and-earn platform built within the **Solana** ecosystem. The platform offers interactive courses, quizzes, and rewards in the form of **SOL tokens** for users who complete learning modules. Users can track their progress through dashboards, earn **NFT certificates**, and participate in community-driven features like leaderboards and forums.



## SolanaQuest - Solana Breakout Hackathon Submission

This project, SolanaQuest, is my solo submission for the [Solana Breakout Hackathon](https://arena.colosseum.org/hackathon) organized by [Colosseum](https://www.colosseum.org/). As a solo participant, I developed this learn-and-earn platform to educate users about the Solana blockchain while rewarding them with SOL tokens for completing courses and quizzes. The platform features interactive modules, gamified elements like leaderboards, and community forums to foster engagement. It aims to contribute to the growth of the Solana ecosystem by making learning accessible and rewarding.

## Project Overview

SolanaQuest aims to:

-   Educate developers about the **Solana blockchain**.
    
-   Provide **SOL token rewards** for completing courses and quizzes.
    
-   Issue **NFT certificates** as proof of course completion.
    
-   Offer **gamification features** such as leaderboards and badges.
    

## Tech Stack

-   **Frontend:** Next.js, Tailwind CSS, Shadcn/UI
    
-   **Backend:** Node.js, Express.js
    
-   **Database:** Supabase (PostgreSQL for database and auth)
    
-   **Web3 Integration:** Solana (Anchor for smart contracts, Wallet Adapter for wallet integration)
    
-   **NFTs:** Metaplex (for minting course completion NFTs)
    
-   **Deployment:** Vercel (Frontend), Railway/Render (Backend)
